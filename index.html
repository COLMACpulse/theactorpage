Before you ask

What happens to my material if this company disappears?

Nothing. It is already on your disk, in ordinary folders, as ordinary files — video as video, data as plain JSON you can read in a text editor. The tools are single HTML files that run without a server. If we vanish tomorrow, the copy you have keeps working.

Do you upload my self-tapes?

No. Nothing leaves your machine unless you publish a showcase page or build a send-link, and then only the files you chose for it. We never see the rest.

Can I use it on more than one computer?

Yes. Free, you move the folder — it is the whole record, so a copied folder is a working install. Paid syncs it for you.

Who is building this?

A working actor, writer and director, for his own use first. Every tool here came out of a job that needed doing on a real set or in a real audition, which is why none of them try to tell you whether the take was any good.
