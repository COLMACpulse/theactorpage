Scripts

Scripts are kept in this browser on this machine. They are not in the app file, so copying the app elsewhere does not bring them along — export the library for that, or keep a script in a file of its own.

Keyboard

EnterNew element, with the type chosen for you. TabAccept the suggested name, or cycle to the next element type. Ctrl + 1–9Set the element type directly. 7, 8 and 9 are section, synopsis and page break, which do not print. Ctrl + B I UBold, italic, underline. Ctrl + DPair this speech with the one above so they print side by side. Ctrl + ZUndo. Element types are undone with the text. Alt + ↑ ↓Move the current element, or everything selected, up or down. BackspaceAt the start of an element, joins it to the one above. Ctrl + SSave the working file. Ctrl + PExport a PDF. Ctrl + FFind and replace.

Select across elements with the mouse or Shift and the arrow keys, then cut, copy or delete as normal. Copying puts Fountain on the clipboard, so it pastes back here with its formatting and into anything else as readable text.

Paste a whole script and it is read as Fountain. Notes in [[double brackets]] stay on screen and stay out of the PDF.
